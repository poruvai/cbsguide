# Contributing to CBSE Guide

Thank you for your interest in contributing to the CBSE Guide! This project aims to help students by providing comprehensive study materials and resources.

## How to Contribute

We welcome contributions from students, teachers, and educators. Here are some ways you can help:

### 1. Adding Study Materials
- Subject notes and summaries
- Important formulas and concepts
- Chapter-wise key points
- Diagrams and illustrations

### 2. Sharing Resources
- Useful websites and apps
- Reference book recommendations
- Study techniques and tips
- Practice questions and answers

### 3. Improving Documentation
- Fixing typos and errors
- Improving explanations
- Adding examples
- Updating outdated information

### 4. Contributing Practice Materials
- Sample questions
- Previous year papers analysis
- Mock test papers
- Solution guides

## Guidelines

### Content Quality
- **Accuracy**: Ensure all information is correct and follows CBSE guidelines
- **Clarity**: Write in clear, simple language that students can understand
- **Relevance**: Keep content aligned with current CBSE syllabus
- **Attribution**: Give credit to original sources when applicable

### Formatting
- Use proper markdown formatting
- Maintain consistent style with existing documents
- Include headers and subheaders for easy navigation
- Use lists and tables where appropriate

### File Organization
```
cbsguide/
├── subjects/
│   ├── class-9-10/
│   │   ├── mathematics/
│   │   ├── science/
│   │   └── social-science/
│   └── class-11-12/
│       ├── science/
│       ├── commerce/
│       └── arts/
├── study-tips/
├── resources/
└── README.md
```

## Step-by-Step Contribution Process

### For Beginners

1. **Fork the Repository**
   - Click the "Fork" button on the repository page
   - This creates a copy in your GitHub account

2. **Make Changes**
   - Edit files directly on GitHub, or
   - Clone to your computer for local editing

3. **Commit Your Changes**
   - Write a clear commit message
   - Example: "Add Class 10 Math formulas for Chapter 1"

4. **Submit a Pull Request**
   - Click "Pull Request" on your fork
   - Describe what you've added or changed
   - Wait for review and feedback

### For Experienced Users

1. **Fork and Clone**
   ```bash
   git clone https://github.com/YOUR-USERNAME/cbsguide.git
   cd cbsguide
   ```

2. **Create a Branch**
   ```bash
   git checkout -b add-chemistry-notes
   ```

3. **Make Changes**
   - Add or modify files
   - Test formatting
   - Check for errors

4. **Commit and Push**
   ```bash
   git add .
   git commit -m "Add Class 11 Chemistry organic notes"
   git push origin add-chemistry-notes
   ```

5. **Create Pull Request**
   - Go to GitHub and create a PR
   - Provide detailed description
   - Link any related issues

### Medium Priority

## Content Standards

### Do's ✅
- Follow CBSE and NCERT guidelines
- Use simple, student-friendly language
- Include examples and explanations
- Cite sources when using external content
- Proofread before submitting
- Maintain respectful tone

### Don'ts ❌
- Copy copyrighted content without permission
- Include incorrect or misleading information
- Use offensive or inappropriate language
- Share paid content illegally
- Promote specific coaching institutes or paid apps
- Include personal contact information

## Review Process

1. **Submission**: You submit a pull request
2. **Initial Review**: Maintainers check basic requirements
3. **Content Review**: Verify accuracy and quality
4. **Feedback**: You may be asked to make changes
5. **Approval**: Once approved, your contribution is merged
6. **Credit**: Your name will be in the contributors list!

## Code of Conduct

### Be Respectful
- Respect different learning styles and abilities
- Be patient with beginners
- Give constructive feedback
- Acknowledge others' contributions

### Be Helpful
- Answer questions when you can
- Share knowledge freely
- Support fellow students
- Encourage learning

### Be Honest
- Give proper attribution
- Don't plagiarize content
- Admit when you're unsure
- Correct your mistakes

## Recognition

## Quick Start for Contributors

**Adding a new study guide:**
1. Fork the repository
2. Create a new markdown file in the appropriate folder
3. Use existing files as templates
4. Submit a pull request with clear description

**Fixing an error:**
1. Fork the repository
2. Make the correction
3. Commit with message like "Fix: Correct formula in Class 10 Math"
4. Submit pull request

**Suggesting improvements:**
1. Open an issue describing your suggestion
2. Wait for feedback from maintainers
3. If approved, proceed with implementation
