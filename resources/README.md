## ✅ Checklist for Board Exams

### 3 Months Before
- [ ] Complete entire syllabus
- [ ] Collect all study materials
- [ ] Start solving sample papers
- [ ] Identify weak areas

### 1 Month Before
- [ ] Intensive revision
- [ ] Daily practice papers
- [ ] Focus on important topics
- [ ] Clear doubts

### 1 Week Before
- [ ] Quick revision of all subjects
- [ ] Revise formulas and key concepts
- [ ] Solve previous year papers
- [ ] Keep calm and positive

### Exam Day
- [ ] Admit card
- [ ] ID proof
- [ ] Stationery
- [ ] Water bottle
- [ ] Reach center early
