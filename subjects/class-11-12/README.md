# Class 11-12 Study Guide

Complete study guide for CBSE Classes 11 and 12 Board Examinations.

## Stream Selection

After Class 10, students choose one of three main streams:
- **Science** (PCM/PCB)
- **Commerce**
- **Arts/Humanities**

## Exam Strategy for Class 11-12

### Time Management
- Start preparation from day one
- Don't rely solely on board exam preparation
- Regular study throughout the year
- Consistent revision cycles

### Board Exam Preparation (Class 12)
1. **3 Months Before**
   - Complete entire syllabus
   - Start solving sample papers
   - Identify weak areas

2. **2 Months Before**
   - Intensive revision
   - Practice previous year papers
   - Focus on important topics

3. **1 Month Before**
   - Daily practice papers
   - Quick revision of formulas/concepts
   - Time-bound mock tests

4. **Last Week**
   - Light revision
   - Review important formulas
   - Stay calm and confident

### Answering Techniques

**For Theory Subjects:**
- Use headings and subheadings
- Write in points when possible
- Underline key terms
- Include diagrams where relevant
- Maintain neat presentation

**For Numerical Subjects:**
- Write formula first
- Show all steps clearly
- Write units in final answer
- Double-check calculations
- Practice different types of problems

While preparing for boards, students often prepare for:
- **Engineering**: JEE Main, JEE Advanced

- **Commerce**: CA Foundation, CS Foundation
- **Arts**: CLAT, DU Entrance exams

**Tip**: Board preparation forms the foundation for these exams. A strong NCERT base helps in competitive exams too.
